Every stage

What each step does, what checks it, and where it broke in testing

0.82 m vs 0.55 m

LiDAR gives real metres, so a cabinet that cannot fit the gap is rejected with an exact reason, before any model is asked. A text prompt never knew the gap was 55 cm.

style 0.10

A narrow cabinet that fit the gap was still rejected: the Decisions API saw from its photo that the colour clashed. Text alone scored a yellow sofa 0.40; the photo scored it 0.86.

56 tests

Every failure we hit is now a test: schema breaks, wrong surfaces, bad sizes, budget overruns, hung model calls.
